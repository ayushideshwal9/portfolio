# portfolio
HTML5 Semantic Portfolio Website with Accessibility and WCAG-compliant structure

This project is a multi-page personal portfolio website created using only HTML5 semantic elements and accessibility best practices.

## Pages

* Home (`index.html`)
* About (`about.html`)
* Projects (`projects.html`)
* Contact (`contact.html`)

## Features

* Semantic HTML5 structure
* Accessible navigation
* ARIA labels
* SEO meta tags
* Accessible contact form
* Multi-page portfolio layout

Created for the Thiranex internship assignment on HTML5 Semantic Structure & Accessibility.
